I made a full stack app with Next.js as the frontend and using Flask for api routes that fetches data from a POSTGRESQL database on Neon. 

Use Google's OAuth to login and get access to the dashboard. From there you can see charts showing how much you have exercised and how many calories you burned. 

Also you can see the complete history of your exercise activity and delete entries.
