This project allows a user to make issues for projects. The information is saved to a NoSQL database (MongoDB). Mongoose is used make the data hold to a schema.

Bootstrap was used for simple styling. Chai and Mocha were used for functional tests that can be ran when the environment variable is set for tests to run.
